플레이스 돋보기 v1.11

가게 이름만 치면 네이버 플레이스 상세와 주변 같은 업종 비교표를 모아 봅니다. 밑그림 없이 가볍게.

01

가게 찾기

[비교표] 네이버 창에서 북마크바의 [돋보기]를 한 번 누르면 지정 가게와 가까운 같은 업종 9곳이 들어옵니다.
[상세 + 비교표] 한 번 누르면 비교표, 가게 화면으로 넘어가면 한 번 더 누르면 상세(리뷰·메뉴·사진)까지 들어옵니다.

다른 방법 · 가게 찾기가 안 될 때
위 칸의 이름으로 지도를 엽니다. 가게를 누른 뒤 [돋보기]를 두 번 누르면 상세가 들어옵니다.
02

즐겨찾기 버튼 처음 한 번만

▼
돋보기 ← 이 버튼을 마우스로 잡아 북마크바로 끌어다 놓으세요.
  1. 북마크바가 안 보이면 Ctrl + Shift + B
  2. 위 [돋보기] 버튼을 북마크바로 끌어다 놓기 — 끝
  3. v1.10에서 버튼이 바뀌었습니다. 예전 [돋보기]는 북마크바에서 오른쪽 클릭 → 삭제하고 새로 끌어다 놓으세요.
  4. 끌기가 안 되면: → Ctrl+Shift+O 북마크 관리자 → ⋮ → 새 북마크 추가 → 이름 돋보기, URL에 붙여넣기 → 저장
원본 붙여넣기로 받기

다른 돋보기에서 [원본 복사]한 내용을 아래 칸에 붙여넣으면 그대로 다시 봅니다.

03

모은 정보

아직 모은 가게가 없습니다.
01에서 가게를 찾고 [비교표]나 [상세 + 비교표]를 누르세요.
